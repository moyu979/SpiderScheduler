# 测试说明文档

## 概述
本目录包含了 `SpiderScheduler` 项目的所有测试文件。测试使用 Python 标准库的 `unittest` 框架编写。

## 目录结构
```
tests/
├── __init__.py
├── README.md
├── run_tests.py
└── utils/
    ├── __init__.py
    └── test_logger.py
```

## 运行测试

### 运行所有测试
```bash
python tests/run_tests.py
```

### 运行特定测试模块
```bash
python tests/run_tests.py tests.utils.test_logger
```

### 直接运行测试文件
```bash
python -m unittest tests.utils.test_logger -v
```

## 测试覆盖范围

### `test_logger.py` - 日志系统测试

#### 1. TestSpiderLogger 类测试
- **初始化测试**: 验证 `SpiderLogger` 实例正确创建
- **目录创建测试**: 验证日志目录自动创建
- **处理器创建测试**: 验证文件处理器和控制台处理器正确创建
- **日志级别设置测试**: 验证不同处理器使用正确的日志级别
- **日志文件命名测试**: 验证按月命名的日志文件
- **日志记录方法测试**: 测试所有日志级别方法（debug, info, warning, error, critical）
- **类名自动检测测试**: 验证自动获取调用类名功能
- **显式类名指定测试**: 验证手动指定类名功能
- **异常日志记录测试**: 验证异常日志包含堆栈跟踪
- **日志级别设置测试**: 验证动态设置日志级别
- **获取底层Logger测试**: 验证获取底层logging.Logger对象
- **月份变化检测测试**: 验证自动切换到新月份日志文件
- **缓存日志功能测试**: 验证日志系统未初始化时的缓存机制
- **缓存刷新测试**: 验证初始化后缓存日志的刷新

#### 2. TestModuleLevelFunctions 类测试
- **模块级函数测试**: 测试所有便捷函数（debug, info, warning, error, critical, exception, log）
- **模块级setLevel测试**: 验证模块级日志级别设置函数

#### 3. TestLoggerIntegration 类测试
- **实际文件日志记录测试**: 验证日志实际写入文件
- **日志格式测试**: 验证日志格式符合预期（时间 - 名称 - 级别 - [类名] - 消息）

#### 4. TestLoggerErrorHandling 类测试
- **日志设置失败处理测试**: 验证配置错误时的错误处理
- **类名获取失败处理测试**: 验证inspect失败时的降级处理

## 测试特点

### 1. 全面覆盖
- 测试了 `SpiderLogger` 类的所有公共方法
- 测试了所有模块级便捷函数
- 测试了错误处理和边界情况

### 2. 隔离性
- 每个测试使用临时目录，避免影响实际日志文件
- 测试后自动清理临时文件和目录
- 重置全局状态，避免测试间相互影响

### 3. Mock 使用
- 使用 `unittest.mock` 模拟外部依赖
- 避免实际的文件系统操作和配置读取
- 专注于测试逻辑而非外部环境

### 4. 实际验证
- 部分测试验证实际的文件写入和格式
- 确保日志系统在真实环境中的正确性

## 测试数据
测试使用中文消息，验证日志系统对中文字符的正确处理。

## 注意事项
1. 测试需要 Python 3.6+ 版本
2. 测试会自动创建和清理临时目录
3. 测试会重置全局状态，确保测试独立性
4. 某些测试依赖 `utils.config.get_path` 函数，使用 mock 进行模拟
